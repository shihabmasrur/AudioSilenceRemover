# AudioSilenceRemover

A simple tool to remove silence from audio files.

## Installation & Usage

### Option 1: Download Pre-built .exe (Easiest - 1 Click)
1. Download `SilenceRemover.exe` from the releases
2. Double-click to run
3. Done! No installation needed

### Option 2: Build from Source (For Developers)

**Requirements:** Python 3.8+

1. **Clone/Download** this project
2. **Open Command Prompt** in the project folder
3. **Run:**
   ```bash
   build.bat
